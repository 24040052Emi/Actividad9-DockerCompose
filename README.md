\## Construccion de la imagen

docker compose build



\## Ejecucion del contenedor

docker compose up -d



\## Acceso a la aplicacion

http://localhost:8080



\## Detener el contenedor

docker compose down



\## Exportar imagen

docker save -o equipo4-angular.tar equipo4-angular:1.0
